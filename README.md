# 2026 디지털혁신 사업계획 — 검색 대시보드 & 분야별 자동분류

행정안전부 기획조정실 디지털혁신 사업계획(35건) 데이터를 활용한 산출물 2종.

## 1. `index.html` — 정적 웹 페이지

브라우저로 파일을 그대로 열어도 동작합니다. **외부 요청 0건**, 데이터 내장형 단일 파일.
(Vercel 루트 URL로 바로 열리도록 파일명을 `index.html`로 둠)

- **사업카드**: 사업번호 · 분야 · 사업명 · 주관기관/기간 · 예산(백만원)
- **키워드 검색**: 사업명 또는 분야 부분일치(대소문자 무시), 일치 부분 형광 강조
- **필터 조건**(모두 AND): 검색 대상(사업명+분야 / 사업명만 / 분야만) · 정확히 일치 · 분야 · 주관기관 · 예산 구간(프리셋 또는 최소·최대 직접 입력)
- **정렬**: 사업번호순 / 예산 많은순 / 적은순 / 사업명 가나다순 / 분야순
- **적용 조건 태그**: 걸어둔 조건을 칩으로 표시, `×`로 개별 해제 / `조건 초기화`로 전체 해제
- **결과 n건 표시**: `검색 결과 n건 (전체 35건 중) · 예산 합계 n백만원`
- **분야별 집계표**: 건수 · 예산 합계 · 예산 비중 · 막대 + 합계 행 (건수 내림차순, 동률 시 분야명 가나다순) — 필터 결과에 연동

전체 기준: 35건 / 88,350백만원 / 4개 분야 (디지털전환 12 · 정보보안 8 · 데이터 7 · 기타 8)

## 2. `solution.py` — 자동화 도구

`사업상세/`의 `.md` 파일을 각 문서의 `분야:` 값에 따라 분야별 폴더로 분류합니다. 표준 라이브러리(`argparse`, `csv`, `pathlib`, `re`, `shutil`, `sys`)만 사용.

```bash
python solution.py --clean
```

| 단계 | 동작 |
|---|---|
| 입력 | `사업상세/*.md` |
| 분야추출 | `<!-- 분야: X -->` 또는 `- 분야: X` (전각 콜론·번호목록·표 형식도 인식). 못 찾으면 `미분류`로 보내고 경고 출력 |
| 처리 | `shutil.copy2`로 `출력_분야별/<분야명>/`에 복사 — **원본 유지**. 동일 파일명은 `(2)` 자동 부여 |
| 출력 | 콘솔 표(건수 + 막대) + `결과_분류현황.csv` + `제출물.md` |

산출물 3종

| 파일 | 내용 |
|---|---|
| `solution.py` | 분류 스크립트 본체 |
| `결과_분류현황.csv` | 헤더 `분야명,건수` / 건수 내림차순 / 동률이면 분야명 가나다순 / UTF-8 |
| `제출물.md` | 과제 개요 · 산출물 목록 · 처리 절차 · 분류 결과표(순위·건수·비율) · 실행 방법 · 예외 처리 |

옵션: `--input` `--output` `--csv` `--md` 경로 지정, `--clean` 출력 폴더 초기화, `--bom` 엑셀용 UTF-8 BOM 저장

실행 결과 — 디지털전환 12, 기타 8, 정보보안 8, 데이터 7 (합계 35건, 4개 분야)

실행 시각 등 비결정적 값을 포함하지 않아 **같은 입력이면 항상 같은 산출물**이 생성됩니다(2회 실행 후 CSV·MD 해시 동일 확인).

## 폴더 구성

```
사업계획데이터.json        원천 데이터(35건)
사업상세/                  사업별 상세 문서 35개(.md)
index.html                 산출물 1 — 정적 웹 페이지
solution.py                산출물 2 — 분류 자동화 스크립트
결과_분류현황.csv           분류 결과 집계 (solution.py 생성)
제출물.md                   과제 요약 보고서 (solution.py 생성)
출력_분야별/               분류 결과 폴더(스크립트로 재생성, 커밋 제외)
vercel.json                Vercel 정적 배포 설정
```

## 배포

Vercel 정적 호스팅. 빌드 과정 없이 `index.html`을 그대로 서빙합니다.

```bash
vercel deploy --prod
```
